# MERRY — магазин детских товаров

Статический магазин на Astro: главная, каталог категории и карточка товара. Вёрстка
снята с макета Figma (ключ файла и карта узлов — `docs/figma.md`), товары и категории
лежат в `src/data/`, страницы каталога и товаров собираются из этих данных.

Проект **собирается, проходит линт, типы и браузерные тесты сразу после
`yarn install`.** Если что-то из этого падает — чинить надо код, а не обходить
проверку.

## Что внутри

| Слой       | Что именно                                                                                       |
| ---------- | ------------------------------------------------------------------------------------------------ |
| Страницы   | `index`, `catalog/[...category]`, `product/[slug]`, `privacy`                                    |
| Данные     | `site`, `nav`, `catalog` (товары и категории), `promo`, `banners`                                |
| Модули     | `carousel`, `catalog`, `timer`, `quantity`, `map-zoom`, `menu`, `reveal`, `parallax`, `gsap`     |
| Компоненты | шапка, подвал, промо, преимущества, категории, ленты, баннер, контакты, фильтры, галерея, атомы  |
| Стили      | `reset.css`, измеренные токены, контейнер 1170 и вертикальный ритм                               |
| Тесты      | шапка, мобильное меню, ленты, фильтры каталога, карточка товара                                  |

## Данные вместо файлов

Новый товар или категория добавляется записью в `src/data/catalog.ts` — роуты,
крошки, ленты, фильтры и пагинация подхватывают её сами. Поля товара: цена и старая
цена, пол и материал (по ним работают фильтры), размеры и цвета (селекты), параметры
(таблица), срок акции (таймер), фотография и её описание.

## Чего в проекте нет

- **Корзины.** Кнопки «В корзину» нарисованы, но страницы и запроса за ними нет:
  сумма и счётчик в шапке — числа из макета.
- **Формы заявки.** В макете её нет ни на одной странице; шаблонная форма и маска
  телефона удалены.
- **Живой карты.** Контакты показывают картинку карты; кнопки «+» и «−» меняют
  масштаб этой картинки.
- **Ссылок на разделы, которых нет в макете.** «Сертификаты», «Фотогалерея», «О
  компании», соцсети и «Войти» ведут в `#`.

## Команды

```
yarn dev            # дев-сервер на 4321
yarn build          # astro check && astro build
yarn preview        # просмотр сборки
yarn lint           # ESLint
yarn lint:styles    # Stylelint
yarn format         # Prettier
yarn test:browser   # Playwright: собирает и поднимает просмотр на 4331
```

**Только Yarn.** `npm install` при наличии `yarn.lock` перепишет его под себя и
сломает установку у коллег на других платформах.

## Что заменить перед публикацией

| Где                        | Что заменить                                   |
| -------------------------- | ---------------------------------------------- |
| `astro.config.mjs`         | `site` — сейчас `https://example.invalid`      |
| `public/robots.txt`        | адрес карты сайта                              |
| `src/components/seo.astro` | `SITE_NAME`, поля `ORGANIZATION`               |
| `src/data/site.ts`         | телефоны, почта, адрес, сумма заказа           |
| `src/pages/privacy.astro`  | текст политики                                 |
| `public/favicon.svg`       | знак магазина                                  |
| `public/og-image.png`      | превью 1200×630 — файла нет, его надо положить |

Контакты в данных взяты из макета и заведомо нерабочие: репозиторий публичный.
